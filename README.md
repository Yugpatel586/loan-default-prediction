# Smart Loan Default and Credit Risk Prediction System Using Machine Learning

## Project Overview
This project predicts whether a customer is likely to default on a loan using Machine Learning. The system analyzes applicant financial information and predicts loan default probability, risk category, and loan approval recommendation.

## Technology Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Flask

### Machine Learning
- Python
- Pandas
- NumPy
- Scikit-learn
